Kusanagi AI

Research tools for physics and materials science. Bring your own AI key; there is no server in between.

01 Add an AI key

Pick a provider and paste its key. It stays in this tab unless you choose to remember it.

02 Open a tool

Run everything offline instead

The desktop apps use a local Ollama model: no key, no network, nothing leaves your machine. 

git clone https://github.com/prathameshnium/Kusanagi-AI.git
cd Kusanagi-AI
pip install -r requirements.txt
python local_apps/launcher.py

To use these web pages offline, run python scripts/serve.py and open http://localhost:8000.
